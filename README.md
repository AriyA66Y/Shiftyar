## 📖 درباره برنامه

**شیفت‌یار** یک اپلیکیشن مدرن، بومی و مینیمال برای کادر درمان (پزشکان، رزیدنت‌ها، اینترن‌ها، پرستاران، ماماها و پرسنل پیراپزشکی) است که به عنوان یک جایگزین کامل و متناسب با نیازهای ایران برای برنامه‌های خارجی مثل SuperShift طراحی شده است.

بزرگ‌ترین مشکل برنامه‌های خارجی، **عدم پشتیبانی از تقویم شمسی** و **عدم همخوانی با ساختار ساعت موظفی و اضافه‌کاری بیمارستان‌های ایران** است. شیفت‌یار این دغدغه‌ها را به‌طور کامل و با ظاهری چشم‌نواز با طراحی **Material You** حل کرده است.

## ✨ امکانات و قابلیت‌های کلیدی

### ۱. تقویم تمام‌شمسی (جلالی)
* نمایش کامل ماه‌های شمسی (فروردین تا اسفند) با ترتیب استاندارد هفته‌های ایران (از شنبه تا جمعه).
* رنگ متمایز روزهای جمعه (تعطیلات) و نشانگر مخصوص روز جاری («امروز»).
* نمایش پلاک و نشانگر رنگی برای هر شیفت روی خانه‌های تقویم.
* ناوبری سریع بین ماه‌ها و دکمه پرش فوری به تاریخ روز.

### ۲. ثبت سریع شیفت‌ها و امکانات سفارشی
* نوار انتخاب سریع پایین صفحه برای تخصیص شیفت تنها با یک لمس.
* شیفت‌های استاندارد بیمارستانی از پیش تعریف‌شده:
  * 🌅 **شیفت صبح (M):** ۶.۵ ساعت (۰۷:۳۰ الی ۱۴:۰۰)
  * 🌇 **شیفت عصر (E):** ۶.۵ ساعت (۱۳:۳۰ الی ۲۰:۰۰)
  * 🌙 **شیفت شب (N):** ۱۲.۵ ساعت (۱۹:۳۰ الی ۰۸:۰۰)
  * ⏳ **شیفت لانگ (L):** ۱۲.۵ ساعت (۰۷:۳۰ الی ۲۰:۰۰)
  * 🚨 **کشیک ۲۴ ساعته (24H):** ۲۴ ساعت (۰۸:۰۰ الی ۰۸:۰۰)
  * 📞 **کشیک آنکال (On-Call):** ۶ ساعت
  * ☕ **مرخصی / آف (Off):** ۰ ساعت
* امکان تعریف شیفت‌های جدید و دلخواه، تغییر ساعات، زمان شروع/پایان و انتخاب رنگ اختصاصی.

### ۳. ثبت یادداشت و پوشش شیفت (جایگزین همکار)
* امکان یادداشت‌گذاری کنار هر شیفت (مثلاً: «تحویل بخش به خانم حسینی»، «شیفت سنگین اورژانس»).
* بخش اختصاصی **«کاور / جایگزین همکار»**: ثبت نام همکار که به جای او شیفت آمده‌اید تا فراموش نشود و بعداً بتوانید شیفت را جبران کنید.
* صفحه مستقل جستجو و فیلتر پیشرفته در میان یادداشت‌ها و اسامی همکاران.

### ۴. محاسبه‌گر هوشمند موظفی و اضافه‌کاری
* تعیین ساعت موظفی ماهانه (۱۴۰، ۱۶۰، ۱۷۵، ۱۹۲ یا عدد دلخواه) با دکمه‌های گام‌شمار سریع.
* تعیین نرخ فی ساعتی اضافه‌کاری به تومان (مثلاً ۱۲۰,۰۰۰ تومان).
* **محاسبه خودکار و بلادرنگ:**
  $$\text{ساعت اضافه‌کاری} = \text{مجموع کارکرد ماه} - \text{ساعت موظفی}$$
  $$\text{دریافتی ناخالص اضافه کار} = \text{ساعت اضافه‌کاری} \times \text{فی هر ساعت}$$
* نمایش وضعیت کسری کار (در صورتی که هنوز به سقف موظفی نرسیده باشید).
* نمودار پیشرفت پر شدن ساعت موظفی و ورود به محدوده اضافه کاری.
* محاسبه‌گر کارانه، حق کشیک مقیمی و مزایای ایاب و ذهاب برای تخمین سرجمع درآمد ماهانه.

### ۵. اشتراک‌گذاری برنامه ماهانه
* دکمه اشتراک‌گذاری برای تولید خروجی متنی شیک و تفکیک‌شده از تمام شیفت‌های ماه جهت ارسال به سرپرستار یا همکاران در پیام‌رسان‌ها (ایتا، بله، واتساپ، تلگرام).

## 🛠 معماری و تکنولوژی‌ها

این پروژه با جدیدترین الگوها و ابزارهای استاندارد اکوسیستم اندروید توسعه داده شده است:

* **زبان:** Kotlin
* **رابط کاربری:** Jetpack Compose با سیستم طراحی **Material Design 3 (Material You)**
* **دایرکشن و فونت:** پشتیبانی کامل از ساختار **راست‌به‌چپ (RTL)** و اعداد فارسی
* **پایگاه داده داخلی:** Room Database بر بستر SQLite با استفاده از KSP (Kotlin Symbol Processing)
* **معماری:** Clean MVVM (Model - View - ViewModel) با `StateFlow` و `Coroutine`ها
* **موتور تقویم شمسی:** الگوریتم محاسباتی ریاضی دقیق و دوطرفه جلالی-میلادی در قالب کاتلین خالص بدون وابستگی به کتابخانه‌های حجیم خارجی
* **تست‌پذیری:** آماده‌سازی تست‌های واحد و کامپوننت با Robolectric

## 🚀 استقرار و خروجی خودکار (CI/CD با GitHub Actions)

این مخزن مجهز به گردش کار خودکار در مسیر `.github/workflows/release.yml` است:

* **با هر بار `git push` به شاخه `main` یا `master`:**
  1. شماره نسخه به‌صورت خودکار بر اساس آخرین تگ، به‌شکل `1.0.x` یک عدد افزایش می‌یابد (مثلاً `1.0.1` ⬅️ `1.0.2` ⬅️ `1.0.3` ...).
  2. متغیرهای `versionName` و `versionCode` در پروژه به‌روزرسانی می‌شوند.
  3. فایل نصبی APK کامپایل می‌شود.
  4. یک **Release** رسمی در گیت‌هاب ایجاد شده و فایل نصبی `ShiftYar-v1.0.x.apk` مستقیماً در قسمت **Assets** برای دانلود عمومی قرار می‌گیرد.

## 💻 راهنمای اجرا و کامپایل محلی

### پیش‌نیازها:
* **Android Studio Ladybug** یا جدیدتر
* **JDK 17** یا بالاتر
* **Android SDK:** حداقل نسخه ۲۴ (Android 7.0) تا نسخه ۳۶

### مراحل اجرا:
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/shiftyar.git
cd shiftyar

# ۲. کامپایل نسخه دیباگ
./gradlew assembleDebug

# ۳. اجرای تست‌های پروژه
./gradlew testDebugUnitTest
```
فایل APK خروجی در مسیر زیر قرار خواهد گرفت:
```
app/build/outputs/apk/debug/app-debug.apk
```
